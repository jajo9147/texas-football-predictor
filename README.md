# 🤘 Texas Longhorns Football Season Predictor & AI Oracle

An interactive College Football Season Predictor, Monte Carlo Game Simulation Arena, and CFP Playoff Scenario Calculator for the Texas Longhorns.

![Texas Longhorns Oracle](https://images.unsplash.com/photo-1587280501635-68a0e82cd5ff?w=1200&auto=format&fit=crop&q=80)

## ⚡ Features
- **10,000-Drive Monte Carlo Game Simulator**: Simulate every drive, momentum swing, and quarter outcome for any game on the schedule (Red River Rivalry vs OU, Lone Star Showdown vs Texas A&M, SEC clash vs Georgia).
- **Interactive Tuning Deck**: Live sliders to tune Arch Manning's QB form, defensive havoc, turnover luck, and DKR crowd noise in real-time.
- **12-Team CFP Playoff Path Calculator**: Toggle wins/losses to dynamically recalculate SEC Championship odds, playoff seeding, and Natty futures.
- **Group Chat Hype Card Generator**: Render and export custom Game Day prediction cards with custom trash talk formatted for iMessage / WhatsApp / GroupMe.
- **Built-in Stadium Audio**: Synthesized referee whistles, touchdown horns, and crowd audio via Web Audio API.

## 🚀 How to Host Live on GitHub Pages in 60 Seconds

1. Open your terminal in this folder:
   ```bash
   cd /Users/jakejohnson/texas-football-predictor
   ```
2. Initialize git and push to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Texas Longhorns AI Season Predictor"
   gh repo create texas-football-predictor --public --source=. --push
   ```
3. Enable GitHub Pages:
   - In your GitHub repo, go to **Settings** > **Pages**.
   - Under **Build and deployment**, set Source to **Deploy from a branch** and select `main` branch.
   - Your live site will be ready at `https://<your-username>.github.io/texas-football-predictor/`!
